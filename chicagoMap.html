Overview

An interactive map of places to visit, eat, and explore around Chicago, built live from a personal Google Sheet of saved spots. Use the toggles below the map to turn each layer on or off, then narrow by type to find exactly the kind of spot you're looking for.

About This Map

The data is read from a Google Sheet each time the page loads, so adding a place to the sheet puts it on the map — no rebuild. Each marker shows the place name, type, neighborhood, address, and any notes captured when it was saved. The built-in assistant can answer questions about any field — ratings, website, phone number, and more.

Curious how the assistant works? Read the agent design write-up for its tool-calling loop, context budget, and guardrails.

The map tiles are served by OpenStreetMap and rendered with Leaflet. Address locations were geocoded with Nominatim.
