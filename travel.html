AI Travel Planner

Overview

A Python and Streamlit app that uses a local Ollama LLM to generate personalized vacation itineraries, track budgets, and answer travel questions — all on-device, no API key required.

Live at allen-travel-agent.streamlit.app .

Features

AI Itinerary Generation

Enter a destination, duration, pace, and budget tier. The LLM returns a structured day-by-day plan with attractions, dining picks, hidden gems, and cultural tips.

Budget & Expense Tracker

Log expenses per trip, monitor spending against a total budget, and view a per-category breakdown chart in real time.

AI Concierge Chat

Ask anything travel-related. The chat is backed by the selected local model and is primed with your saved preferences for context-aware answers.

Packing & Pre-Trip Checklists

Auto-generated packing lists and a time-bucketed preparation timeline (8 weeks → day before) based on destination and activities.

Stack

  • Python — app logic and LLM prompt engineering
  • Streamlit — reactive UI with sidebar routing
  • Ollama — local inference (Llama 3.1, Mistral, Granite, DeepSeek R1)
  • pandas — expense tables and budget breakdowns

Conclusion

This project showed that local LLMs can power practical productivity tools without cloud APIs. The key engineering tradeoff was enforcing a strict JSON response schema — limiting model expressiveness in exchange for reliably parseable output — with a rule-based fallback so the UI never breaks.
